Linux Subjective Assessment
1. Configure SMTP in Localhost
Objective:
Set up SMTP service on the local system to enable sending emails.
Steps:
1. Install SMTP server (e.g., Postfix).
2. Configure Postfix for local-only delivery.
3. Test using mail or sendmail.
Commands:
sudo apt update
sudo apt install postfix -y
sudo nano /etc/postfix/main.cf
myhostname = localhost
myorigin = /etc/mailname
inet_interfaces = loopback-only
inet_protocols = all
sudo systemctl restart postfix
echo "Test mail from postfix" | mail -s "Test Subject"
yourusername@localhost

Objective:
Create a service that logs the current time every minute into a file in the user's home
directory.
Steps:
1. Create the time logging script.
2. Create the systemd service file.
3. Create the systemd timer file.
4. Reload systemd and enable the timer.
5. Check status and logs.
6. Stop the service.
Commands:
nano /usr/local/bin/showtime.sh
sudo chmod +x /usr/local/bin/showtime.sh
sudo nano /etc/systemd/system/showtime.service
sudo systemctl daemon-reexec
sudo systemctl daemon-reload
sudo service showtime start
cat showtime.log
sudo service showtime stop
