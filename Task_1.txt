1. Configure SMTP in Localhost
Objective:
Set up SMTP service on the local system to enable sending emails.
Steps:
1. Install SMTP server (e.g., Postfix).
2. Configure Postfix for local-only delivery.
3. Test using mail or sendmail.
Commands:
sudo apt update
sudo apt install postfix -y
sudo nano /etc/postfix/main.cf
myhostname = localhost
myorigin = /etc/mailname
inet_interfaces = loopback-only
inet_protocols = all
sudo systemctl restart postfix
echo "Test mail from postfix" | mail -s "Test Subject"
yourusername@localhost
